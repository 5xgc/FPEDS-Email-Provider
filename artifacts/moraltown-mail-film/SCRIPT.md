# MoralTown Mail — Web & Desktop Film

## Director's treatment

- **Promise:** A private, access-key mailbox for the web, with a Windows desktop companion, built and owned by MoralTown.
- **Identity:** Use the supplied white MoralTown mark on black. Extend the product's existing black, warm-white, and restrained red interface palette; the red is an app accent, not a newly asserted official brand color. Space Grotesk carries display type, DM Sans supports interface copy, and JetBrains Mono marks keys and system details.
- **Hero:** The MoralTown mark becomes the recurring carrier between real product-interface illustrations: a key ring, an open inbox, a message panel, settings, and a Windows installer card.
- **Motion:** A restrained virtual camera tours a compact world of UI surfaces; red rules and envelope forms carry compound cuts; oversized type resolves in short, timed bursts.
- **Arc:** Brand hook → access-key entry → inbox and folders → message detail → sending and receiving → precise privacy/account controls → Windows companion and ownership lockup.
- **Payoff:** The detailed web interface collapses into the supplied mark on a clean, high-contrast closing field, with the ownership statement locked beside it.
- **Format/runtime:** 16:9 landscape, 30 seconds. Seven shots total 30,000 ms. No voiceover or sound effects; one instrumental bed. On-screen UI data is fictional demo content.
- **Claim boundary:** Say “encrypted at rest,” not “end-to-end encrypted.” The film shows access-key sign-in, per-mailbox organization, and administrator lockdown without claiming that providers or transport networks cannot process mail.

## Variety and claim review

- Each neighboring shot changes at least two of framing, field, hero scale, or dominant motion mechanic.
- A visible change occurs at least once per second; the opener changes twice within its first second.
- No shot ends in an empty field. The final lockup remains readable while its ring begins the loop handoff.
- Real mailbox content is not used. The only provided image is the supplied MoralTown mark.
- Security language is limited to access-key login, encrypted-at-rest mailbox fields, separated mailbox identities, and the site's admin-only lockdown behavior. The film does not claim end-to-end encryption or provider-free delivery.
